Функционал чат-бота:
Бот выполняет следующие ключевые задачи:

Запись клиента на сделку (кнопка «Записаться на сделку»): позволяет пользователю бота выбрать необходимую услугу / услуги банка.
Ответ на интересующий клиента вопрос (кнопка «Задать вопрос»): предполагает выход на консультанта и обсуждение вопроса со специалистом.
Ознакомление пользователя с услугами банка (кнопка «Посмотреть услуги банка»): выводит банковские услуги в виде древовидного меню, по которому клиент может перемещаться для выбора интересующей услуги.
Сохранение контактных данных пользователя для связи сотрудника банка с клиентом.

Логика работы бота
Пользователь отправляет команду /start, которая запускает диалоговое окно. Приветствие бота сопровождается демонстрацией основного меню, где клиент может выбрать тип взаимодействия с банковским сервисом: «Записаться на сделку», «Задать вопрос», «Посмотреть услуги банка».
При нажатии кнопки главного меню автоматически подтягивается субменю по выбранной функции меню. При выборе пункта субменю осуществляется переход по древовидной структуре системы меню и уточняется характер сделки. После выбора требуемой услуги бот предлагает пользователю оставить свой номер телефона для обратного звонка из банка.

Методы API
Метод GET /deal-info/all – метод получения информации о записи на консультацию со специалистом

Входные параметры: status (query параметр) – значения True, False или отсутствует совсем

Выходные данные (массив JSON объектов):

  "id": "integer",
  "user_id": "string",

  "status": "boolean",
  "creation_time": "string",
  "tg_username": "string",
}

Алгоритм работы:
Данный метод предоставляет информацию о записях клиентов на консультацию со специалистом, полученную из таблицы deals.
У метода есть query параметр status. Status – показывает, подтвердил ли клиент консультацию со специалистом или нет.
Если запрос отправляется без параметра, то будут получены все данные со статусом True и False.
Если запрос отправляется со status = True, то будут получены все данные со статусом True.
Если запрос отправляется со status = False, то будут получены все данные со статусом False.
